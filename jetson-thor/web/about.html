Use it from your agent

Base URL https://arpanpathak.taildb9a39.ts.net/v1, model name anything, key from the author. The guide covers each tool, including how to turn thinking on and off.

# openbatrangs (Linux and macOS)
cargo install --git https://github.com/arpanpathak/openbatrangs --locked
openbatrangs --openai-url https://arpanpathak.taildb9a39.ts.net/v1 \
             --api-key-file ~/.config/thor-chat/api-key
curl https://arpanpathak.taildb9a39.ts.net/v1/models \
  -H "Authorization: Bearer $KEY"

Questions

What hardware is this?

An NVIDIA Jetson AGX Thor developer kit: a 14-core Arm CPU and a Blackwell GPU sharing 128 GB of memory. The model is Nemotron 3 Nano 30B-A3B, quantized to 8 bits, served by llama.cpp.

Why is it sometimes slower?

Four replies are generated at once at most. Generating is limited by memory bandwidth (273 GB/s), so when everyone is typing, each reply gets a share of it. A fifth person waits for a slot.

Who can see what I send?

Your messages are processed on the author's machine, not stored by a cloud provider. The chat history lives in your browser. Don't send secrets.

Is it free?

Yes, while it lasts. It runs on electricity at someone's home, so access is limited in time and can be withdrawn.

Can I run this myself?

Yes. The book walks through the whole setup, from the first SSH login to serving the model and sharing it safely.
